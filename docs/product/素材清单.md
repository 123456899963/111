# 素材清单与规范（内容扩展 X-07）

> 依据：[ADR-0003](../development/ADR/ADR-0003-content-expansion.md)（已采纳）、[PRD_扩展提案.md](PRD_扩展提案.md) Q4/Q5 答复。
> 本文件只解决"素材怎么放、怎么命名、缺了怎么办、怎么回溯来源"，不记录业务规则（以 PRD / API 契约为准）。

---

## 1. 硬性约束

1. **禁止盗用外链**：图片与视频一律落本站 `/uploads/`，禁止 `<img src="https://...">` 指向第三方图床。
2. **禁止 AI 生成图冒充实拍图**：当前首页背景与茶品图片均为 **Wikimedia Commons 的 CC0 / 公共领域照片**，属于**品类示意**，不得宣称是某款具体茶品（如"西湖龙井"）的实拍；正式上线前应替换为自有实拍或已获商业授权的图片。
3. **不留死链**：任何素材缺失时，前端必须落到统一占位图或整块隐藏（视频），不得出现 404 图片或空播放器。
4. **可回溯**：每份素材必须在 §5 清单登记来源；来源不明的素材不得入库。

## 2. 目录与命名

| 类型 | 落盘路径 | 命名 | 说明 |
|---|---|---|---|
| 首页装饰背景 | `frontend/public/images/banners/` | `banner-{category}.webp`（首选）→ `.jpg`（备选）→ `.svg`（占位兜底） | 六类各一；组件按 WebP→JPG→SVG 顺序自动回退，放文件即生效，无需改代码 |
| 茶品主图 / 图片集 | `backend/uploads/{YYYY}/{MM}/{uuid}.{jpg,png,webp}` | 服务端 UUID | 由 `POST /admin/upload` 生成，禁止手工改名 |
| 茶品视频 | `backend/uploads/videos/{YYYY}/{MM}/{uuid}.mp4` | 服务端 UUID | 由 `POST /admin/media/video` 生成 |
| 前端内置占位 | `frontend/src/components/` 内联 SVG | — | TeaCard / 详情页现有的占位实现，不新增图片文件 |

> 素材**物理文件**由后端统一 UUID 命名；本清单只记录"哪个茶/哪类"对应"哪个 URL"，作为追溯依据。

## 3. 格式与体积

| 类型 | 格式 | 上限 | 前端处理 |
|---|---|---|---|
| 茶品主图 | JPEG / PNG / WebP | 5 MB | 建议 1200×900、WebP 质量 80，单张 ≤ 300 KB |
| 图片集 | 同上 | 5 MB / 张 | 单茶最多 9 张；缩略图 `loading="lazy"` |
| 视频 | MP4（H.264 + AAC）优先；MOV 兼容 | 50 MB、≤ 180 秒 | `preload="metadata"`，不自动播放 |
| 首页背景 | WebP（已落地 6 张）/ SVG（兜底） | 单张 ≤ 300 KB | 首张 `eager`，其余 `loading="lazy"` |

上传格式与体积由服务端魔数校验（`app/services/upload.py`），前端提示仅为体验优化，不构成安全边界。

---

## 4. 缺失兜底

| 场景 | 兜底行为 |
|---|---|
| 茶品无主图 / 主图加载失败 | `TeaCard`、`TeaDetailView` 渲染内置茶叶 SVG 占位，不显示破图 |
| 图片集为空 | 详情页不渲染缩略图行（`v-if="galleryImages.length > 1"`） |
| 无视频 / 视频加载失败 | 详情页整块隐藏视频区（`hasVideo=false`），不留空播放器 |
| 首页背景某张加载失败 | `HeroBackground` 将该图移出轮播；全部失败时不渲染背景层，保留原渐变 |

### 5.4 登记规则

- **来源**填写：摄影师 / 授权图库名称 + 图片 ID / 自行拍摄（注明拍摄地点与日期）。
- **授权**填写：CC0、CC BY（附署名要求）、商业授权编号、自有版权。
- 未登记来源的素材一律不得进入 `uploads/` 生产目录。
- 替换占位图时保持文件名不变（如 `banner-green.webp`），避免改动前端引用。
- CC0 / 公共领域虽无署名义务，仍保留文件页链接以便回溯与替换。
