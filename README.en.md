# Tea · Guide —— Structured Knowledge Base Platform for Six Major Tea Categories

[English Version](#english)

---

## Project Introduction

Tea · Guide is a structured knowledge base platform focusing on China's six major tea categories (Green Tea, White Tea, Yellow Tea, Oolong Tea, Black Tea, Dark Tea). It aims to provide tea culture enthusiasts with a systematic, comprehensive, and easy-to-use tool for tea information retrieval and learning.

### Core Objectives

- Build a complete knowledge system for the six major tea categories
- Provide convenient tea information retrieval and filtering functions
- Support user favorites and tasting note recording
- Create a science popularization and communication community for tea culture

---

## Function Modules

### MVP (First Version Core Functions)

| Module | Function Description |
|------|----------|
| **Home Page** | Display popular teas, recommended content, and educational tips |
| **Tea List Page** | Support multi-dimensional filtering by tea category, origin, year, etc. |
| **Tea Detail Page** | Display detailed tea information, images, and taste descriptions |
| **Registration & Login** | User account system, supporting favorite functionality |
| **Favorites List** | List of user-favorited teas, supporting tasting notes |
| **Sharing Function** | Tea item link sharing |
| **Admin Dashboard** | Data maintenance and management |

### Phase 2 Functions (Planned)

- List Page OR Condition Switch
- Extended Filtering Dimensions
- Detail Page Image Sets and Videos
- Related Recommendation Algorithm
- Share Image Posters
- Multi-List Management
- User Contribution System (Add new teas, submit educational content)
- Admin Audit Dashboard
- Personalized Recommendations and Hot Recommendations Algorithms

## Tea Catalog Card Fields

### Required Fields

- Tea Category (One of the six major categories)
- Tea Name
- Origin
- Processing Method Description
- Dry Leaf Appearance
- Liquor Color
- Taste Profile Description
- Brewing Suggestions

### Optional Fields

- Year
- Grade
- Brand
- Reference Price
- Storage Recommendations
- Benefits & Characteristics

### Tips Section

Officially released educational knowledge, brand stories, and other extended content.
